# Ping-Pong-Loader

A simple, lightweight ping-pong style loader built with plain HTML, CSS and JavaScript.

![Preview of the loader](./Screenshot%202024-08-23%20130523.png)

## Overview

This repository contains a small animated loader that mimics a ping-pong / bouncing ball effect. It's perfect as a starting point for adding a playful loading indicator to a website or for learning CSS animations and basic DOM structure.

- Languages: HTML, CSS, JavaScript
- No build tools or dependencies required — just open `index.html` in your browser.

## Demo / Preview

Open `index.html` in any modern browser to see the loader in action. The screenshot above shows the visual style and animation when the loader is running.

## Files

- `index.html` — Markup for the loader and demo page.
- `style.css` — Styling and animations for the loader.

## How to use

1. Clone or download this repository.
2. Open `index.html` in your browser.

To embed the loader into an existing page, copy the relevant HTML from `index.html` and the CSS from `style.css` into your project.

## Customization ideas

- Change colors in `style.css` to match your brand.
- Adjust animation timing or easing for different pacing.
- Add accessibility features like `aria-hidden` or descriptive text for screen readers if the loader conveys important state.
